## Current Architecture / Workflow Design

### Five-Node Pipeline (aligned with CLAUDE.md)

| Node | File | Model | Role |
|------|------|-------|------|
| Orchestrator | `backend/app/orchestrator.py` | None (pure Python) | Routes requests, asyncio.gather(), SSE emission |
| Form Workflow | `backend/app/workflows/form_workflow.py` | claude-3-5-haiku-20241022 | Parses team form data into FormEvalJSON |
| Matchup Workflow | `backend/app/workflows/matchup_workflow.py` | claude-3-5-haiku-20241022 | Parses H2H matchup data into MatchupEvalJSON |
| Odds/Risk Workflow | `backend/app/workflows/odds_risk_workflow.py` | claude-3-5-haiku-20241022 | Parses odds/injury data into OddsRiskEvalJSON |
| Final Prediction Agent | `backend/app/agents/final_prediction.py` | claude-sonnet-4-6 | Synthesizes three eval JSONs into FinalPredictionJSON |

Note: Haiku agents are "parsers" (structured extraction), Sonnet is the "synthesizer" (probabilistic reasoning).

### Tool Files (one per workflow)
- `backend/app/tools/web_form_tool.py` — form data retrieval tool definition
- `backend/app/tools/web_matchup_tool.py` — matchup data retrieval tool definition
- `backend/app/tools/web_odds_risk_tool.py` — odds/risk data retrieval tool definition

### Data Flow
```
POST /api/analysis/stream?game_id=X   (single game) — Q3 PENDING user decision
  -> FastAPI route
  -> orchestrator.run_pipeline(game_context)
       -> asyncio.gather(form_workflow, matchup_workflow)  [cached per game_id]
       -> odds_risk_workflow()                             [always fresh, ~30min TTL]
       -> final_prediction_agent.synthesize(form, matchup, odds)
  -> SSE events streamed at each stage boundary
```

### SSE Event Taxonomy
- `agent_start` — emitted when each workflow begins
- `agent_complete` — emitted with full payload when workflow finishes
- `agent_error` — emitted on partial failure (pipeline continues with partial telemetry)
- `pipeline_complete` — final FinalPredictionJSON output

**`form.py`** — FormEvalJSON (output of form_workflow)

- TeamFormData: team_id, team_name, last_10_record (wins/losses), home_record, away_record, key_players: list[PlayerStatus], recent_game_log: list[str]

**`matchup.py`** — MatchupEvalJSON (output of matchup_workflow)
- H2HGame: date, home_team, away_team, home_score, away_score, winner
- MatchupEvalJSON: game_id, h2h_last_10: list[H2HGame], h2h_record_home_team: wins/losses, h2h_record_away_team: wins/losses, venue_advantage_note: str, standalone_probability: float, analysis_notes: str

**`odds_risk.py`** — OddsRiskEvalJSON (output of odds_risk_workflow)
- InjuryEntry: player_name, team_id, status, notes
- OddsRiskEvalJSON: game_id, injury_report: list[InjuryEntry], moneyline_home: float, moneyline_away: float, spread: float, over_under: float, market_implied_probability: float (home), standalone_probability: float, analysis_notes: str

**`prediction.py`** — FinalPredictionJSON (output of final_prediction agent)
- FinalPredictionJSON: game_id, predicted_winner: str, confidence: float (0-1), risk_rating: Literal["LOW","MEDIUM","HIGH"], reasoning_narrative: str, form_weight: float, matchup_weight: float, odds_weight: float, signal_disagreement_flag: bool, partial_telemetry: bool, extended_thinking: bool (always False for now)

**`base.py`** — (new file to create) Shared types
- GameContext: game_id, home_team_id, away_team_id, game_date, venue
- SSEEvent: event_name, payload: dict, timestamp
- AgentError: agent_name, error_type, error_message, timestamp

**`__init__.py`** — re-exports all public models from all submodules

## Decisions Made

1. **Claude 3.5 Haiku for workflows** — latency-sensitive parallel parsers; cost-effective.
2. **Claude Sonnet 4.6 for Final Prediction Agent** — needs deep probabilistic synthesis across three conflicting signal sources.
3. **tool_use pattern** — force structured output via single-tool schema. Proven in example_agent.py.
4. **Graceful degradation** — agent failure caught at orchestrator, emits agent_error SSE, passes None to Final Prediction Agent which signals uncertainty via partial_telemetry: bool.
5. **Schema package split** — `backend/app/schemas/` with domain files: form.py, matchup.py, odds_risk.py, prediction.py, base.py.
6. **SSE named events** — agent_start, agent_complete, agent_error, pipeline_complete.
7. **AsyncAnthropic client** — instantiated once at module level per workflow file.
8. **Extended thinking: OFF by default** — `extended_thinking: bool = False` flag on FinalPredictionJSON so it can be toggled without rewriting the agent.
9. **Mock data for now** — real NBA API integration is a later milestone. Mock .txt files in `backend/app/mock_data/` serve as workflow inputs.
10. **Q3 PENDING** — single game_id vs batch endpoint: user asked for plain-language explanation before deciding.
